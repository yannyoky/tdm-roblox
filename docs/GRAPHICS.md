# Графика

У игры одна версия графики: реалистичная. Простой «кубической» версии больше нет.

## Что где

| Что | Где |
| --- | --- |
| `Lighting.LightingStyle = Realistic` (бывший Technology = Future), `PrioritizeLightingQuality` | `default.project.json` (из скрипта не меняется, ставит Rojo) |
| Свет, время суток, атмосфера, облака, Bloom, цветокоррекция, лучи солнца по картам | `Config/Decor.luau` → `Lighting`, применяет `server/World/Ambience.luau` |
| Отделка карт: окна, карнизы, тротуары, разметка, фонари, деревья, мелочь на улицах, дворы, базы | `server/World/Detailer.luau`, `Config/Decor.luau` |
| Земля из Terrain с травой, свет в зданиях | `server/World/Realism.luau`, `Config/Graphics.luau` |
| PBR-материалы из MaterialService, размытие в прицеле | `client/Graphics.luau`, `Config/Graphics.luau` |

Настроения карт: Промзона — пасмурно и смог, Спальный район — ясное утро, Порт — закат с фонарями,
Деревня — тёплый день.

## Ассеты в месте (Place)

Ассеты лежат в самом месте, не в Git, поэтому место нужно сохранять (Ctrl+S).

- **MaterialService**: официальный пак Roblox
  [Modern City Materials Pack](https://create.roblox.com/marketplace/asset/13168345645/Modern-City-Materials-Pack).
  Код сам подставляет вариант для каждого материала. Вариант с именем из `Config/Graphics.MaterialOverrides`
  (например `Real_Concrete`) важнее, чем выбранный автоматически. Ненужный вариант просто удалите из MaterialService.
- **ServerStorage/DecorModels** (или прежняя `RealisticModels`): `Container` и `Crate` — модель или папка с
  моделями, заменяют процедурные контейнеры и ящики. Прежняя коробка остаётся невидимой для столкновений и попаданий.
  Скрипты из моделей удаляются при вставке на карту.
- Деревья и кусты на карте — меши из `server/World/DecorAssets.luau`.

## Что дальше (Blender)

Когда появятся свои модели, они заменяют бесплатные в тех же местах:

- Здания: 3–4 жилых дома, гараж, склад/цех, ларёк. Фасады с окнами и рамами.
- Окружение: фонарь, заборы, бетонные блоки, мусорные баки, бочки, поддоны, кусты и деревья.
- Порт: кран, причальные тумбы. Машины: корпуса для автопарка фракций.

Требования: до ~10–20 тыс. треугольников на здание, текстуры 1024 (крупное) / 512 (мелочь),
PBR через SurfaceAppearance, простая коллизия (Box/Hull).

## Производительность

Realistic-свет, тени света в зданиях и фар нагружают слабые телефоны. Если будет тормозить:
`Shadows = false` в `server/World/Realism.luau`, меньше `Scatter`/`Street` в `Config/Decor.luau`.
Размытие в прицеле игрок выключает в настройках, на низком качестве графики оно выключено само.
