# Реалистичная графика (ветка graphics)

В этой ветке игра выглядит «реалистично»: свет Future, дымка, пост-эффекты, земля из Terrain с травой,
фонари, свет в зданиях, настоящие фары. В `main` остаётся обычный вид Roblox.

## Как вести две ветки

- Весь геймплей делаем в `main` (или в ветках от неё).
- Ветку графики время от времени обновляем: `git merge main` в ветке графики. Код графики живёт в отдельных
  файлах, поэтому конфликтов почти не будет.
- Выпускать можно обе версии как два разных места (Place) в одном опыте или как два отдельных опыта.

## Что уже сделано кодом

| Что | Где |
| --- | --- |
| `Lighting.Technology = Future`, мягкие тени, отражения окружения | `default.project.json` (из скрипта Technology менять нельзя) |
| Настроение по карте: время суток, дымка Atmosphere, облака, Bloom, ColorCorrection, SunRays | `src/shared/Config/Graphics.luau` → `Moods` |
| Глубина резкости: лёгкое размытие вдали, в прицеле фокус на цели и размытие своего оружия | `src/client/Graphics.luau`, `Config/Graphics.luau` → `DepthOfField` |
| Земля из Terrain (трава шевелится), под дорогами и зданиями земля и асфальт, чтобы трава не торчала | `src/server/World/Realism.luau` |
| Фонари вдоль дорог (горят на карте «Порт», где вечер) | там же, `StreetLamps` |
| Свет под потолком в зданиях с интерьером | там же, `InteriorLights` |
| Фары машин (SpotLight с тенями) | там же, `Headlights` |
| Подмена стандартных материалов своими PBR-материалами, если они есть в MaterialService | `Config/Graphics.luau` → `MaterialOverrides` |
| Настройки игрока «Реалистичная графика» и «Размытие вдали и в прицеле» (для слабых устройств) | `Config/Settings.luau` |

Настроения карт: Промзона — пасмурно и смог, Спальный район — ясное утро, Порт — закат и фонари,
Деревня — тёплый день.

## Что нужно сделать в Studio один раз

1. Lighting → проверьте, что **Technology = Future** (Rojo ставит сам, но если подключались к старому месту, поставьте руками).
2. Workspace → Terrain → **Decoration = вкл.** (травинки; скрипт пытается включить, но это свойство может быть закрыто для скриптов).
3. Уберите из Lighting старые Sky/Atmosphere/Bloom, если они есть в месте, чтобы не накладывались.
4. Game Settings → Rendering: ничего менять не нужно, но тестируйте на «Graphics Quality = 10» и на низком качестве.

## Что нужно найти или сделать (ассеты)

Код этого не заменит: это картинки и модели, которые загружаются в Roblox и дают им ID.

### 1. PBR-материалы (самое заметное, с них стоит начать)

Для каждого материала нужен набор из 4 текстур 1024×1024 (ColorMap, NormalMap, RoughnessMap, MetalnessMap).
Источники с бесплатной лицензией CC0: ambientCG, Poly Haven, или бесплатные MaterialVariant в Creator Store.
В Studio: MaterialService → Insert → MaterialVariant, имя ровно как ниже, BaseMaterial как в таблице,
вставить 4 текстуры. Код подхватит сам.

| Имя MaterialVariant | BaseMaterial | Что это |
| --- | --- | --- |
| `Real_Concrete` | Concrete | бетон, плиты |
| `Real_Brick` | Brick | кирпичные стены |
| `Real_Asphalt` | Asphalt | дороги |
| `Real_WoodPlanks` | WoodPlanks | полы, заборы, ящики |
| `Real_RustyMetal` | CorrodedMetal | контейнеры |
| `Real_Metal` | Metal | столбы, балки, шасси |
| `Real_DiamondPlate` | DiamondPlate | пандусы, броня |
| `Real_Grass` | Grass | трава (и Terrain) |
| `Real_Sandbags` | Sand | мешки с песком |
| `Real_Fabric` | Fabric | флаги, колёса |

Для Terrain материалы меняются так же: MaterialVariant с BaseMaterial Grass/Concrete/Asphalt применится и к земле.

### 2. Небо (Sky)

Набор из 6 картинок скайбокса (или готовый Sky из Creator Store) на каждое настроение:
пасмурное небо (Промзона), ясное утро (Спальный район), закат (Порт), летний день (Деревня).
Пока используется стандартное небо Roblox с Atmosphere, это уже выглядит неплохо.

### 3. Модели из Blender (MeshPart + SurfaceAppearance)

Серые коробки сейчас собираются кодом. Для настоящего реализма нужны модели.
Делать их можно постепенно: код карт уже размечает, где что стоит.

- Здания: 3–4 варианта жилого дома, гараж, склад/цех, ларёк. Фасады с окнами и рамами.
- Окружение: фонарный столб, забор (сетка и деревянный), бетонный блок, мусорный бак, бочка, поддоны, мешки, шины, кусты и деревья.
- Порт: кран, контейнер с рёбрами и дверями, причальная тумба, вода (Terrain Water).
- Машины: корпуса для автопарка фракций (вместо коробок из деталей). Колёса и физика остаются как есть.
- Персонажи: реалистичные скины фракций как модели одежды/брони (это ветка скинов, тут только графика окружения).
- Оружие делается в ветке оружия, здесь не дублируем.

Требования к моделям: до ~10–20 тыс. треугольников на здание, текстуры 1024 (крупное) / 512 (мелочь),
PBR-текстуры как SurfaceAppearance, коллизия — простая (Box/Hull), LOD Roblox делает сам.

### 4. Мелочи для «жизни»

- Декали: трещины, пятна, разметка дорог, граффити банды, таблички силовиков.
- Частицы: пыль от пуль по бетону, искры по металлу, пар из труб в промзоне.
- Звуки окружения: ветер, чайки в порту, гул промзоны.

## Производительность

- Future + тени фар и света в зданиях заметно нагружают слабые телефоны. Игрок может выключить
  «Реалистичную графику» в настройках, на низком качестве графики сами выключаются SunRays и размытие.
- Фонари идут без теней, у света в зданиях и фар тени есть. Если будет тормозить, поставьте `Shadows = false`
  в `src/server/World/Realism.luau`.
