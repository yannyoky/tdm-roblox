# Ассеты из Creator Store

Всё подключено **по id в коде**, поэтому живёт в git и не теряется вместе с плейсом. Скрипты из бесплатных моделей не используются: из моделей взяты только меши, картинки и звуки.

## Что где

## Как заменить

- **Звук**: найдите в Creator Store → Audio, скопируйте id, впишите в `Sounds.luau` как `id(123456)`.
- **Оружие**: проще всего положить свою модель в `ServerStorage/WeaponModels/<Id оружия>` (с деталью `Handle`), она важнее записи в `WeaponMeshes.luau`. Чтобы вернуть старую модель из деталей, удалите запись оружия из `WeaponMeshes.luau`.
- **Одежда**: нужен id **картинки** шаблона (не id товара). Вставьте модель NPC в Studio, у её `Shirt`/`Pants` возьмите `ShirtTemplate`/`PantsTemplate`.
- **Машина**: физика (шасси, колёса, сиденья) прежняя, меш только рисуется поверх. Чтобы вернуть кузов из деталей, удалите запись из `VehicleMeshes.luau` (и при желании верните `Width`/`Length` в `Config/Vehicles.luau`).
- **Деревья и мелочь**: числа в `Decor.Scatter`, пятна на земле в `Decor.Patches`.

## В Studio один раз

Скрипт не может менять технологию освещения. Для чётких теней выберите **Lighting → Technology = ShadowMap** (или Future, но это тяжелее).

## Осторожно с бесплатными моделями

Многие бесплатные модели прячут скрипты-ловушки. Например, модели автора «Content Deleted - 158552482» с подписью «No scripts» на деле содержат скрипт `Runtime`, который строит поддельное окно «Troubleshoot» с командной строкой. Такие модели не использовать. Если всё-таки вставляете модель, сначала удалите из неё все `Script`, `LocalScript` и `ModuleScript`.
