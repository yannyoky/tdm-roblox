# TDM: Банда против силовиков

Командный шутер для Roblox со сценариями. Две стороны: **Банда** и **Силовики**.

Режимы в MVP:

- **Перестрелка** — классический командный бой до 50 убийств или 8 минут, возрождение через 3 секунды.
- **Капт** — одна команда атакует район, другая держит. Раунды без возрождения, стороны меняются, матч до 3 побед.

Между матчами игроки голосуют в лобби за следующий режим.

Что ещё есть:

- **Арсенал:** автомат, пистолет-пулемёт, дробовик, пулемёт, снайперская винтовка (прицел на ПКМ), пистолет, револьвер, нож, бита. Оружие открывается по уровню.
- **Снаряжение:** осколочная, дымовая и светошумовая гранаты, бронежилет.
- **Инвентарь без ограничений:** кнопка «Инвентарь», берёшь в бой любое открытое оружие и снаряжение, хоть всё сразу.
- **Физика попаданий:** урон по зонам тела (голова, корпус, конечности), падение урона с дистанцией, разброс и дробь считает сервер, пули пробивают тонкие стены из дерева, пластика и стекла, рэгдолл при смерти, бойцы не толкают друг друга телами.
- **Ранения:** смертельный урон сначала ранит. Раненый ползёт и истекает кровью 20 секунд, союзник поднимает его, удерживая E 3 секунды, враг может добить. Сильный хедшот убивает сразу.
- **Боты:** добивают каждую команду до 4 бойцов и уходят, когда заходят игроки. Видят и стреляют с задержкой реакции, не видят сквозь дым, слепнут от светошумовой, идут в зону капта и поднимают раненых союзников. Настройки в `src/shared/Config/Bots.luau`.
- **Звания:** у банды от Шестёрки до Авторитета, у силовиков от Рядового до Полковника. Опыт идёт за сторону, за которую играешь.
- **Ежедневные задания и сезонный пропуск:** 3 задания в день, 30 уровней пропуска, бесплатная и премиум-дорожка, награды монетами и титулами.
- **Рейтинг и лидеры:** рейтинг Эло в матчах, где в каждой команде от 2 живых игроков, таблицы лидеров по рейтингу, победам и убийствам (кнопка «Прогресс»).

## Как запустить

1. Установите [Roblox Studio](https://create.roblox.com/) и [VS Code](https://code.visualstudio.com/).
2. Установите [Rokit](https://github.com/rojo-rbx/rokit) и в папке проекта выполните `rokit install` (поставит Rojo).
3. В Studio установите плагин Rojo (Plugins → Manage Plugins или из [Creator Store](https://create.roblox.com/store/asset/13916111004)).
4. В папке проекта выполните `rojo serve`.
5. В Studio откройте новое место (Baseplate), во вкладке Plugins нажмите **Rojo → Connect**. Код появится в игре.
6. Для сохранений: Game Settings → Security → **Enable Studio Access to API Services** (место нужно один раз опубликовать).
7. Тест: вкладка **Test → Play**, в главном меню нажмите **Играть**. Матч стартует даже с одним игроком, остальные места займут боты. Для теста с людьми: **Test → Clients and Servers**, 2 игрока.

Если в Workspace нет папки `Map`, игра сама построит тестовую арену. Свою карту стройте в Studio по структуре:

```
Workspace/Map/
  Spawns/Bandits/  -- детали, где появляется Банда
  Spawns/Gov/      -- детали, где появляются Силовики
  Spawns/Lobby/    -- детали в лобби
  CapturePoints/   -- плоские прозрачные детали-зоны для капта (CanCollide и CanQuery выключены)
```

Сохраните карту в файл места (`.rbxl`), сам файл в Git не попадает.

## Как устроен код

```
src/
  shared/              -- ReplicatedStorage.Shared, видно и серверу, и клиенту
    Config/            -- все настройки: оружие, режимы, команды, боты, бой, звания и задания (Meta), магазин
    Net.luau           -- сетевые события
  server/              -- ServerScriptService.Server
    Services/
      MatchService     -- лобби, голосование, команды, появление, матч, итоги
      WeaponService    -- серверная проверка выстрелов и урона
      DataService      -- уровень, опыт, монеты, сохранение
      ShopService      -- Game Passes и Developer Products
      MapService       -- карта или тестовая арена
      BotService       -- боты: тела и поведение
      DamageService    -- урон, броня, ранения, поднятие
      GrenadeService   -- гранаты
      PhysicsSetup     -- группа столкновений персонажей, рэгдолл
      ProgressionService -- звания, задания, сезонный пропуск, рейтинг, табличка над головой
      SkinService      -- скины фракций: открытие, выбор, покупка за монеты
      LeaderboardService -- глобальные таблицы лидеров
    Modes/
      ModeBase         -- общий интерфейс режима
      TDM, Capture     -- режимы
  client/              -- StarterPlayerScripts.Client
    WeaponController   -- стрельба, перезарядка, прицел, трассеры
    Hud                -- интерфейс матча и магазин
    InventoryMenu      -- инвентарь
    ProgressMenu       -- звания, задания, пропуск, рейтинг, лидеры
    CombatFx           -- ослепление, экран ранения, броня, тряска камеры
    Ui, Menus          -- общие помощники интерфейса и система окон с горячими клавишами
    MainMenu           -- главное меню: выбор стороны, «Играть»
    SkinMenu           -- скины фракций с предпросмотром
    SettingsMenu, PlayerSettings -- настройки (чувствительность, FOV, тряска, подсказки)
    Scoreboard         -- таблица игроков по Tab и экран итогов матча
    DeathScreen        -- экран смерти и камера на убийцу
    Hotbar             -- своя панель оружия вместо стандартной
    Movement           -- бег, присед, паркур
  character/           -- StarterCharacterScripts: своя регенерация здоровья
```

Попадания считает сервер: клиент сообщает только «выстрелил отсюда туда», сервер проверяет скорострельность, патроны и стены.

### Как добавить новый сценарий

1. Скопируйте `src/server/Modes/TDM.luau` в новый файл, например `Drop.luau`.
2. Переопределите нужные функции (`Start`, `OnTick`, `OnPlayerKilled`, `CanRespawn`, `GetWinner`, `Cleanup`). Описание — в `ModeBase.luau`.
3. Добавьте запись в `src/shared/Config/Modes.luau` (в `List` и `Order`). Режим сразу появится в голосовании.

## Управление

| Клавиша | Действие |
|---|---|
| ЛКМ / ПКМ | огонь / прицел |
| R | перезарядка |
| 1–9, Q | оружие из слота, прошлое оружие |
| G | граната (повторно — следующий тип) |
| Shift / C | бег / присесть |
| Пробел у препятствия | перелезть, забраться |
| E / F / T | поднять союзника или за руль / пассажиром / перевернуть машину |
| Tab | таблица игроков |
| M / I / U / J / B | меню / инвентарь / скины / прогресс / магазин |

На телефоне всё это кнопки на экране, на геймпаде: L1/R1 — листать оружие, B — присесть, Select — таблица.

## Скины

Скины фракций описаны в `src/shared/Config/Skins.luau`: цвета формы и снаряжение (шлем, бронежилет, балаклава, бандана, кепка, цепь и т. д.). Снаряжение строится из деталей кодом, без загрузки моделей, и не ловит пули, поэтому хитбоксы у всех одинаковые. Лицо и причёска остаются от аватара игрока, одежда меняется на форму своей стороны, чтобы своих и чужих было видно издалека.

Скин открывается одним из способов: есть у всех, за звание фракции, за монеты, за уровень сезонного пропуска или Game Pass «Набор скинов» (`Shop.GamePasses.SkinPack`).

## Модели оружия

Оружие в руках собирается из деталей кодом (`src/server/Services/WeaponModels.luau`): ствол, магазин, рукоять, приклад, прицел. Чтобы поставить свою модель (из Creator Store или Blender), положите Model в `ServerStorage/WeaponModels` с именем оружия (`Rifle`, `SMG`, `Shotgun`, `LMG`, `Sniper`, `Pistol`, `Revolver`, `Knife`, `Bat`, `Frag`, `Smoke`, `Flash`). Внутри должна быть деталь `Handle`: за неё держит рука, ствол смотрит в сторону −Z детали. По желанию в `Handle` можно добавить Attachment `Grip` (куда встанет рука) и `Muzzle` (дуло, откуда идут трассер и вспышка). Скрипты из модели удаляются, детали не ловят пули.

## Голосовой чат по близости

Кода не требует, включается в настройках игры: Creator Hub → игра → **Communication** (или в Studio: Game Settings → Communication) → включить **Microphone / Enable voice chat**. Голос по умолчанию пространственный: слышно тех, кто рядом. Доступен игрокам 13+ с подтверждённым возрастом.

## Монетизация

1. Опубликуйте игру, затем в [Creator Hub](https://create.roblox.com/dashboard/creations) создайте Game Passes «VIP», «Премиум-пропуск» и «Набор скинов» и Developer Products (пакеты монет, буст опыта), задайте цены.
2. Вставьте их Id в `src/shared/Config/Shop.luau`. Пока Id равен 0, кнопка в магазине показывает «скоро».

Платная только косметика и удобство: VIP даёт +25% опыта и монет, буст даёт x2 опыта на час, премиум-пропуск даёт вторую дорожку наград сезона. Оружие открывается игрой.
